# Electronics Tools

> **Source note:** Component names, basic purpose, connection guidance, and example uses are based on the uploaded **Microcontroller Boards Reference** document. Short student explanations are added to make the material easier to learn. Exact pin labels, voltage limits, polarity, and module variants must be checked on the actual component before wiring.

Tools support safe assembly, measurement, testing, and repair.

| No. | Tool | What It Does | How to Use | Example Use |
|---:|---|---|---|---|
| 70 | Wire Stripper | Removes insulation without intentionally cutting the conductor. | Select the correct wire-size opening and strip only the needed length. | Preparing jumper/hook-up wire |
| 71 | Fixed-Voltage Soldering Kit | Heats solder to create permanent electrical joints. | Use only with appropriate training, ventilation, stand, eye protection, and adult/school supervision. | PCB/wire assembly |
| 72 | Digital Multimeter | Measures electrical quantities such as voltage, current, and resistance. | Select the correct mode/range and place probes correctly for the measurement type. | Testing and debugging |
| 73 | Electric Tester | Detects the presence of electrical voltage/current depending on tester type. | Follow the exact tester instructions and school electrical-safety rules. | Safety checks |
| 74 | Precision Screwdriver Set | Tightens or loosens small screws used in electronic/mechanical assemblies. | Select the correct screwdriver size and avoid excessive force. | Assembly/disassembly |

## Safety
Student electronics work should remain within approved low-voltage systems unless supervised by a qualified adult using appropriate procedures.
