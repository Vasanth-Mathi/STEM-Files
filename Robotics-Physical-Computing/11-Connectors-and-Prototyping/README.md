# Connectors and Prototyping

> **Source note:** Component names, basic purpose, connection guidance, and example uses are based on the uploaded **Microcontroller Boards Reference** document. Short student explanations are added to make the material easier to learn. Exact pin labels, voltage limits, polarity, and module variants must be checked on the actual component before wiring.

These items help students build temporary or permanent electrical connections.

| No. | Item | How It Works | How to Use / Connect | Example Use |
|---:|---|---|---|---|
| 64 | 800-Pin Solderless Breadboard | Internally connected metal strips join selected holes without solder. | Insert components and jumper wires into the correct connected rows/rails. | Temporary prototypes |
| 65 | Male Berg Strips | Provide rigid header pins for plug-in electrical connections. | Solder to PCB/module or mate with compatible female headers. | Board/module connections |
| 66 | Male-Male Jumper Cable | Connects two female sockets/breadboard holes. | Insert each male end into the required connection point. | Breadboard wiring |
| 67 | Male-Female Jumper Cable | Connects a male pin to a female socket/breadboard point. | Use the male and female ends according to connector type. | Sensor/module wiring |
| 68 | Female-Female Jumper Cable | Connects two exposed male header pins. | Push each female end onto the required pin. | Module-to-module connections |
| 69 | Hook-Up Wire, 5 m | Insulated wire used for custom-length permanent wiring. | Cut, strip, and solder/terminate safely. | Permanent project wiring |

## Breadboard Habit
Before powering a circuit, trace every connection from source to component to GND.
