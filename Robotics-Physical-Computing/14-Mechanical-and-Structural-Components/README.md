# Mechanical and Structural Components

> **Source note:** Component names, basic purpose, connection guidance, and example uses are based on the uploaded **Microcontroller Boards Reference** document. Short student explanations are added to make the material easier to learn. Exact pin labels, voltage limits, polarity, and module variants must be checked on the actual component before wiring.

Mechanical parts give a robot its physical structure and allow electrical motion to become useful movement.

| No. | Component | How It Works | How to Assemble / Connect | Example Use |
|---:|---|---|---|---|
| 80 | BO Wheel | Fits onto a compatible motor shaft and transfers motor rotation to the ground. | Mount securely and keep wheels aligned. | Robot movement |
| 81 | Chassis Set Box | Stores chassis components together for organised access. | Keep matching hardware, mounts, wheels, and fasteners together. | Parts organisation |
| 82 | Chassis Set | Forms the mechanical frame that supports boards, sensors, motors, battery, and wiring. | Assemble according to the chassis design and mount components securely without shorting electronics. | Robot platform |

## Mechanical Check
A robot can fail even when the code and wiring are correct. Check wheel alignment, loose fasteners, motor mounting, weight distribution, and cable movement.
