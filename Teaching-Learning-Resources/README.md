# Teaching & Learning Resources

Teaching and learning resources support hands-on, inquiry-based, and project-based STEM education. This section is intended for classroom activities, lesson ideas, worksheets, project references, examples, guides, and other materials that help educators and learners explore STEM concepts in practical ways.

## How Teaching & Learning Resources Work

Resources are most effective when they connect learning objectives with clear activities, student exploration, reflection, and opportunities to apply concepts.

```text
Learning Goal ---> Activity / Resource ---> Student Exploration ---> Practice / Project ---> Reflection / Assessment
```

Materials in this section may support teachers in planning lessons, running workshops, guiding projects, differentiating activities, and helping students develop problem-solving and critical-thinking skills.

## Common Use Cases

- Classroom lesson planning
- STEM club activities
- Teacher training
- Student worksheets
- Project guides
- Workshop resources
- Assessment ideas
- Demonstration activities
- Inquiry-based learning
- Project-based learning
- Educator reference materials
- Student extension activities
