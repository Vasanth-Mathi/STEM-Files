# Datasets, Statistics and Data Literacy

| Resource | Link | Useful For | Access |
|---|---|---|---|
| Our World in Data | https://ourworldindata.org/ | Global datasets and charts on health, population, energy, environment, education, technology | Free; many charts/data reusable with attribution |
| Our World in Data - Teaching | https://ourworldindata.org/teaching | Guidance for classroom use of charts/data | Free |
| Gapminder Tools | https://www.gapminder.org/tools/ | Interactive global data visualisation over time | Free |
| Gapminder for Teachers | https://www.gapminder.org/for-teacher/ | Teacher guides and global-data classroom materials | Free |
| World Bank Open Data | https://data.worldbank.org/ | Development indicators across countries and time | Free |
| UN Data | https://data.un.org/ | International statistics across population, economy, environment and society | Free |
| UNESCO Institute for Statistics | https://uis.unesco.org/ | Education, science, culture and communication statistics | Free |
| OECD Data | https://data.oecd.org/ | Economic, social, education and development indicators | Free browsing/downloads |
| Data Commons | https://datacommons.org/ | Public statistical datasets connected across places and topics | Free |
| Kaggle Datasets | https://www.kaggle.com/datasets | Large collection of user/community datasets | Free browsing; account and data quality vary |
| FiveThirtyEight Data Archive | https://data.fivethirtyeight.com/ | Historical datasets used in data journalism | Free archive; topic/date coverage varies |
| Google Dataset Search | https://datasetsearch.research.google.com/ | Search engine for datasets published across the web | Free search |

## Data Investigation Pattern

```text
Question -> Dataset -> Clean -> Visualise -> Interpret -> Limitations -> Conclusion
```

Never let the graph become more confident than the data.
