# Electronics, Engineering and Coding Tools

| Tool | Link | Useful For |
|---|---|---|
| Tinkercad Circuits | https://www.tinkercad.com/circuits | Breadboard circuits, Arduino simulation, basic electronics, sensors, LEDs, servos, and virtual prototyping |
| CircuitVerse | https://circuitverse.org/ | Free open-source digital logic simulation, truth tables, gates, sequential circuits, subcircuits, and timing diagrams |
| Falstad Circuit Simulator | https://falstad.com/circuit/ | Fast visual exploration of analog and digital circuits, waveforms, filters, and component behaviour |
| Wokwi | https://wokwi.com/ | Browser-based simulation of Arduino, ESP32, microcontrollers, displays, sensors, and embedded projects; free use is available with some platform features varying by plan |
| Arduino Documentation | https://docs.arduino.cc/ | Official board references, language/API documentation, tutorials, and hardware information |
| Scratch | https://scratch.mit.edu/ | Block-based programming, animations, games, events, variables, conditions, and computational thinking |
| MIT App Inventor | https://appinventor.mit.edu/ | Block-based Android app development, sensors, interfaces, data, and device interaction |
| Microsoft MakeCode for micro:bit | https://makecode.microbit.org/ | Block and text coding for micro:bit, simulation, radio, sensors, and physical computing |
| Python Tutor | https://pythontutor.com/ | Visualising program execution step by step for Python and several other languages |
| GitHub Skills | https://skills.github.com/ | Guided practice for Git, GitHub repositories, collaboration, pull requests, and developer workflows |

## Engineering Use

Use simulators to test ideas, but verify important hardware projects on the real components before claiming the design is proven.
