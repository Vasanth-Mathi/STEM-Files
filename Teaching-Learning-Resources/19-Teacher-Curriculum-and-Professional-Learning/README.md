## Teacher Resource Check

Before using an online activity, ask:

- Does it match the learning outcome?
- Is it suitable for the age/grade?
- What prior knowledge is required?
- Is student login required?
- Is the material accessible on school devices?
- Can students show evidence of learning?
- What licence applies if I modify or redistribute it?
