# Mathematics Tools and Resources

Interactive tools for algebra, geometry, graphs, statistics, manipulatives, modelling, and mathematical exploration.

| Tool | Link | Useful For |
|---|---|---|
| GeoGebra | https://www.geogebra.org/ | Graphing, geometry, 3D geometry, CAS, statistics, probability, transformations, constructions, and interactive math resources |
| Desmos | https://www.desmos.com/ | Graphing functions, tables, sliders, regressions, geometry, 3D exploration, and visual investigation |
| Mathigon Polypad | https://mathigon.org/polypad | Virtual manipulatives such as number tiles, algebra tiles, geometry pieces, fractions, probability tools, and classroom demonstrations |
| Mathigon | https://mathigon.org/ | Interactive mathematics courses, activities, puzzles, and visual explanations |
| WolframAlpha | https://www.wolframalpha.com/ | Checking calculations, symbolic mathematics, plots, equations, statistics, units, and mathematical data | 
| Khan Academy Mathematics | https://www.khanacademy.org/math | Lessons, practice, worked examples, and structured mathematics learning |
| NRICH Mathematics | https://nrich.maths.org/ | Rich mathematical problems, investigations, reasoning tasks, and classroom challenges |
| PhET Mathematics Simulations | https://phet.colorado.edu/ | Interactive simulations that connect mathematics with visual and physical models |

## Classroom Ideas

- compare two graphs by changing one parameter,
- investigate transformations with sliders,
- use Polypad before moving from concrete to symbolic algebra,
- ask students to predict before using a calculator,
- use tools to verify reasoning rather than replace reasoning.
