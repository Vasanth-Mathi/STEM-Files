# Chemistry Tools and Virtual Labs

| Tool / Library | Link | Useful For |
|---|---|---|
| ChemCollective | https://chemcollective.org/ | Virtual chemistry labs, scenario-based activities, tutorials, concept tests, stoichiometry, acid-base work, thermochemistry, solubility, and redox |
| ChemCollective Virtual Lab | https://chemcollective.org/vlab | Performing virtual aqueous-chemistry experiments with reagents and lab equipment |
| PhET Chemistry Simulations | https://phet.colorado.edu/ | Interactive simulations for atoms, molecules, reactions, solutions, gases, pH, and other chemistry concepts |
| MolView | https://molview.org/ | Drawing molecules and viewing molecular structures in 2D and 3D |
| PubChem | https://pubchem.ncbi.nlm.nih.gov/ | Chemical structures, properties, identifiers, compounds, safety-related information, and scientific references |
| Royal Society of Chemistry Periodic Table | https://www.rsc.org/periodic-table | Element data, properties, trends, history, and periodic-table exploration |
| NIST Chemistry WebBook | https://webbook.nist.gov/chemistry/ | Reference data for chemical and physical properties, spectra, and thermochemical information |
| Chemistry LibreTexts | https://chem.libretexts.org/ | Free chemistry textbooks, chapters, examples, and learning resources |

## Safety Note

Virtual labs are useful for learning concepts and planning, but they do not replace real laboratory safety training.
