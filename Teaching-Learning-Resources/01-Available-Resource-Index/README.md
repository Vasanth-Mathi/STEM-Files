# Available Resource Index

## Purpose
This page lists teaching and learning resources that are already available in the current STEM-Files repository or in the working curriculum materials used to build it.

## Resources Available Now

| Resource | What It Contains | How It Can Be Used |
|---|---|---|
| Arduino Projects Collection | 59 Arduino projects arranged from beginner input/output activities to advanced robotics | Guided builds, circuit practice, coding practice, troubleshooting, project extension |
| ESP32 & IoT Projects Collection | Wi-Fi, Bluetooth/BLE, ESP-NOW, Blynk IoT, sensor networks, and remote-control projects | IoT lessons, wireless communication, networking, multi-board systems |
| AI Student Prompt Library | Detailed prompts for tutoring, research, maths, science, coding, project planning, presentation, responsible AI, and revision | AI-literacy activities, independent learning, prompt engineering, reflection |
| Robotics & Physical Computing Component Handbook | Student-friendly reference for 82 components from the uploaded hardware document | Component identification, connection planning, hardware theory, lab orientation |
| Microcontroller Boards Reference | Original 17-page source document containing boards, sensors, outputs, motors, electronics, tools, power, and structural parts | Teacher reference and lab inventory learning |
| STREAM.AI Curriculum Framework Draft | Grade-wise curriculum structure, measurable outcomes, projects, evidence, tools/materials, and mastery expectations | Curriculum planning, module design, assessment planning |
| STREAM.AI School Proposal | Programme structure, implementation approach, progression, school discussion points, learning evidence, and resource planning | Leadership discussion, curriculum planning, programme implementation |

## Important Distinction
Detailed final lesson plans, bootcamp instructions, guided project worksheets, capstone briefs, assessment rubrics, and portfolio templates are **resource types to be developed for classroom delivery**. They should not be described as already completed unless the actual files exist.
