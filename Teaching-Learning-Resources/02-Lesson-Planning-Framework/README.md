# Lesson Planning Framework

## Purpose
A simple framework teachers can use when converting an existing project or curriculum objective into a classroom lesson.

## Lesson Structure

### 1. Learning Goal
Write what students should understand or be able to do by the end of the lesson.

Good learning goals use observable actions such as:
- identify
- explain
- connect
- calculate
- program
- test
- compare
- troubleshoot
- improve

### 2. Prior Knowledge
Identify what students must already know.

Examples:
- digital input/output
- breadboard basics
- conditions
- sensor purpose
- safe power connections

### 3. Starter / Readiness Check
Use 2-4 short questions or a small task to check prerequisite understanding.

### 4. Teacher Demonstration
Show only the minimum new idea required for the activity.

A useful pattern is:

```text
Explain ---> Demonstrate ---> Student Predicts ---> Student Tries
```

### 5. Guided Practice
Students complete a small task with checkpoints.

### 6. Independent or Team Application
Students modify, extend, test, or apply the idea in a new context.

### 7. Evidence
Decide before the lesson what will show learning.

Possible evidence:
- working circuit
- code explanation
- measurement table
- screenshot
- design sketch
- test result
- debugging note
- short oral explanation

### 8. Reflection
Ask students:
- What worked?
- What failed?
- What did you change?
- What evidence supports your conclusion?
- What would you improve?

## Planning Checklist
- Is the goal measurable?
- Is the activity possible with available time and equipment?
- Are safety limits clear?
- Does every student have an individual learning responsibility?
- Is there a way to check understanding besides seeing the final product?
