# AI Literacy and Responsible Use Resources

## Purpose
Support AI learning that goes beyond asking a chatbot for answers.

## Available Resource
The repository now contains a dedicated **AI Student Prompt Library** covering:
- personal tutoring
- Socratic questioning
- concept explanation
- research and source checking
- mathematics problem solving
- science investigation planning
- coding/debugging
- design thinking
- project planning
- presentation/viva practice
- hallucination and bias investigation
- active revision

## AI Literacy Concepts to Teach
- prompt and context
- data
- training
- labels and features
- prediction
- confidence
- errors
- hallucination
- bias
- privacy
- verification
- attribution
- limitations

## Responsible Student Workflow

```text
Ask ---> Receive ---> Question ---> Verify ---> Revise ---> Acknowledge
```

## Classroom Evidence
- original prompt
- revised prompt
- AI output
- claim-check record
- student corrections
- source verification
- explanation of what the student changed
- reflection on limitations

## Teacher Reminder
AI-assisted work should make student thinking more visible, not less visible.
