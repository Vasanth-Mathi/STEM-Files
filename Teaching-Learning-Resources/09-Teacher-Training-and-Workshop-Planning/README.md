# Teacher Training and Workshop Planning

## Purpose
Provide a simple structure for running practical STEM or technology workshops for educators.

## Workshop Structure

### Before the Workshop
- define participant level
- identify one measurable outcome
- check device/software/hardware access
- prepare a working demonstration
- prepare a backup activity
- identify safety and privacy requirements

### During the Workshop

```text
Context ---> Demonstration ---> Guided Practice ---> Independent Task ---> Share / Reflect
```

### Suggested Evidence
- participant-created sample
- short implementation plan
- reflection
- troubleshooting notes
- exit question

## Workshop Topics Supported by Current Materials
- Arduino fundamentals
- ESP32 and IoT
- physical computing
- robotics
- prompt engineering
- AI in education
- responsible AI
- cyber safety / digital citizenship
- project-based learning
- design thinking
- STEM assessment and learning evidence

## Follow-Up
Ask participants to identify:
- one idea they can implement,
- one resource they need,
- one possible barrier,
- one way they will know the implementation worked.
