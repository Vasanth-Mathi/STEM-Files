# Digital Tools and Platforms

## Purpose
List the software and platforms already referenced across the available curriculum and project materials.

| Tool / Platform | Learning Use |
|---|---|
| Scratch | Creative coding, games, events, loops, conditions, variables |
| MIT App Inventor | Mobile app design, events, interface components, procedures, lists, stored data |
| Tinkercad Circuits | Simulated electronics, Arduino logic, sensors, LEDs, buzzer, servo |
| Arduino IDE / Arduino-compatible environment | Physical computing and microcontroller programming |
| ESP32 tools | Wi-Fi, Bluetooth, ESP-NOW, IoT, sensor networks |
| Blynk IoT | Remote dashboards, datastreams, monitoring, and control |
| Teachable Machine | Introductory no-code image/pose/sound classification and AI data literacy |
| Spreadsheet tools | Tables, graphs, test data, percentages, comparison, analysis |
| PowerPoint | Project presentations and exhibitions |
| Canva | Visual presentations and project communication |
| Figma / Framer | Interface/prototype exploration where evaluated and school-approved |

## Selection Rule
Choose a tool because it supports the learning goal, not because it is fashionable or available.

## Questions Before Using a Platform
- What skill will students learn?
- Is student access age-appropriate?
- What data does the platform collect?
- Is login required?
- Does the school approve the platform?
- Can learning evidence be saved/exported?
- Is there an offline or backup option?
