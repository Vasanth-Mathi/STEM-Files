# Assessment, Quizzing and Feedback Tools

Online service plans change frequently. Check school privacy policy, student age requirements, account needs and current free-tier limits before use.

| Tool | Link | Useful For | Access Note |
|---|---|---|---|
| Google Forms | https://forms.google.com/ | Exit tickets, quizzes, surveys, self-marking checks, data collection | Google account; school domain rules apply |
| Microsoft Forms | https://forms.microsoft.com/ | Quizzes, polls, surveys, classroom checks | Microsoft account/school licensing may apply |
| Kahoot! | https://kahoot.com/ | Live game-based quizzes and review | Free and paid features vary |
| Plickers | https://www.plickers.com/ | Whole-class response using printed cards and one teacher device | Free/paid features vary |
| Mentimeter | https://www.mentimeter.com/ | Live polls, word clouds, ranking, formative checks | Free/paid limits vary |
| Socrative | https://www.socrative.com/ | Quizzes, quick questions, exit tickets | Plans vary |
| Formative | https://www.formative.com/ | Live formative assessment, responses, feedback, assignments | Plans vary |
| Quizlet | https://quizlet.com/ | Retrieval practice, flashcards and study sets | Free/paid features vary |
| H5P | https://h5p.org/ | Interactive questions, videos, presentations and content types | Open-source technology; hosting/platform conditions vary |
| Moodle Quiz | https://docs.moodle.org/ | Question banks, quizzes and assessment inside Moodle | Open-source LMS; requires hosting |
| Classkick | https://www.classkick.com/ | Live student work, teacher feedback and formative checks | Plans vary |

## Assessment Principle

Use quizzes to identify **what to teach next**, not merely to produce scores.
