# Physical Computing and Robotics Teaching Resources

## Purpose
Connect the existing Arduino, ESP32, and physical-computing references into a teaching pathway.

## Resources Available
- **Arduino Projects:** 59 projects from basic input/output to robotics
- **ESP32 & IoT Projects:** wireless communication, Blynk, ESP-NOW, networking, and IoT
- **Robotics & Physical Computing Handbook:** reference for 82 components
- **Microcontroller Boards Reference:** original hardware document

## Suggested Learning Progression

```text
Component Identification
        |
        v
Simple Input / Output
        |
        v
Sensor + Decision + Output
        |
        v
Automation
        |
        v
Motor / Servo Control
        |
        v
Robot / IoT System
        |
        v
Testing + Troubleshooting + Improvement
```

## Student Questions for Every Build
- What is the input?
- What is the output?
- What decision does the controller make?
- What power source is used?
- Which component must not be connected directly to a controller pin?
- What value needs calibration?
- What should happen if a sensor gives an invalid reading?
- How will we test whether the system is reliable?

## Evidence
Circuit record, code explanation, measured values, calibration notes, test trials, fault log, improvement, and final demonstration.
