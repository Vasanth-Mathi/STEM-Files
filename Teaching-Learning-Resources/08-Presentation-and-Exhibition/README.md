# Presentation and Exhibition Resources

## Purpose
Help students communicate project evidence clearly during demonstrations, exhibitions, and viva-style questioning.

## Suggested Presentation Structure

1. Problem or need
2. User / context
3. Project goal
4. Requirements and constraints
5. Idea / design
6. How the system works
7. Important circuit, code, model, or process
8. Testing method
9. Results
10. Failure or limitation
11. Improvement from Version 1 to Version 2
12. Final evaluation
13. Individual learning
14. Sources and acknowledgements

## Slide Design Principles
- One clear idea per slide
- Short text
- Readable font
- Use real evidence rather than decorative screenshots
- Label diagrams
- Show test results
- Do not hide failures
- Cite external material

## Viva Questions
- Why did you choose this approach?
- What would happen if this component failed?
- What did you personally build or decide?
- Which test result changed your design?
- What is the biggest limitation?
- What would Version 3 improve?
- What evidence shows the project meets its goal?

## Available Tools Referenced in Current Materials
PowerPoint and Canva can be used for presentation preparation, subject to school access and policy.
