# Concept Map Builder Prompt

## Purpose
Help students organise relationships between ideas instead of keeping facts as isolated points.

## Detailed Prompt
```text
Act as my concept-map coach.

Grade: [enter]
Subject: [enter]
Central topic: [enter]
Terms/concepts I already know: [enter]

1. Ask me to identify the central concept in my own words.
2. Help me group related terms into 3-6 meaningful clusters.
3. For every connection, require a linking phrase such as:
   - causes,
   - depends on,
   - is an example of,
   - changes when,
   - produces,
   - is measured by.
4. Do not accept lines between concepts without explaining the relationship.
5. Ask me which relationships are strongest and which are uncertain.
6. Identify missing prerequisite concepts.
7. Flag any relationship that needs factual verification.
8. Produce a text-only map structure after I attempt the relationships.
9. Ask me to redraw the map independently.
10. End with 5 questions that require moving across two or more links.

Do not invent relationships simply to make the map look complete.
```

## Student Evidence
First map, corrected map, relationship phrases, and verification notes.
