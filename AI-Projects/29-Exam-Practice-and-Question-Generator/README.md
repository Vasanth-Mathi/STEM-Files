# Exam Practice and Question Generator Prompt

## Purpose
Generate practice based only on the student's supplied syllabus or notes.

## Detailed Prompt
```text
Act as my exam-practice coach.

Grade/course: [enter]
Syllabus/topics: [paste]
Notes/source material: [paste if needed]
Question style: [MCQ / short answer / problem / essay / mixed]
Difficulty: [enter]

1. Create a balanced practice set covering the supplied topics.
2. Do not introduce topics outside the supplied syllabus unless labelled extension.
3. Do not show answers initially.
4. Give questions in small batches.
5. After I answer, mark each response with:
   - correct/partly correct/incorrect,
   - missing idea,
   - correction,
   - next practice target.
6. Track repeated errors.
7. Re-test weak topics later using different questions.
8. End with a topic-by-topic readiness summary based only on this session.

Do not invent an official exam pattern, mark scheme, or board requirement unless I provide it.
```

## Student Evidence
Answer set, error log, weak-topic list, and re-test results.
