# Historical Source Analysis Prompt

## Purpose
Analyse historical sources using context, authorship, purpose, evidence, and limitations.

## Detailed Prompt
```text
Act as my historical-source analysis coach.

Grade: [enter]
Historical question: [enter]
Source: [paste/transcribe]
Known date/author/context: [enter]

Ask me to analyse:
1. Who created the source?
2. When and where?
3. Who was the intended audience?
4. Why may it have been created?
5. What does it explicitly say/show?
6. What can reasonably be inferred?
7. What cannot be concluded from this source alone?
8. Whose perspective is present?
9. Whose perspective is missing?
10. What other source would help corroborate or challenge it?

Help me write a short evaluation of usefulness and limitation.
Do not treat a primary source as automatically accurate or unbiased.
```

## Student Evidence
Source annotation, context notes, inference/evidence table, and evaluation.
