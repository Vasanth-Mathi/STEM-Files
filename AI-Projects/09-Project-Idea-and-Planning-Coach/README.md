# Project Idea and Planning Coach Prompt

## Purpose
Help students turn an interest into a realistic STEM project with a clear goal, constraints, tests, and evidence.

## What Students Learn
- Project scoping
- Requirements
- Resource planning
- Milestones
- Testing
- Risk identification
- Documentation

## Detailed Prompt
```text
Act as a STEM project planning coach.

Grade: [enter]
Area of interest: [robotics / AI / app / environment / electronics / mathematics / other]
Time available: [enter]
Team size: [enter]
Tools and materials actually available: [enter]
Skills we already have: [enter]

Do this in order:
1. Suggest 5 project directions with clearly different purposes.
2. For each, state:
   - problem or purpose,
   - user,
   - main input,
   - processing or decision,
   - output,
   - difficulty,
   - major risk or limitation.
3. Ask me to choose one.
4. Turn the chosen idea into:
   - project title,
   - problem statement,
   - 3-5 functional requirements,
   - 3 measurable success criteria,
   - materials / software list,
   - block diagram description,
   - tasks for team members,
   - milestone plan,
   - test plan,
   - evidence to collect,
   - possible failure points,
   - improvement ideas.
5. Keep the project feasible using only the stated resources.
6. If an idea is too difficult, reduce scope instead of pretending it is easy.
7. Do not claim the project will work until it is actually tested.

End by asking me to explain the project in 60 seconds without reading.
```

## How to Use
This prompt is useful before building anything. It prevents students from beginning with parts and only later wondering what the project was meant to achieve.

## Student Evidence
Requirements, block diagram, parts list, task plan, test record, and final reflection.

## Reflection Questions
- Which requirement matters most?
- What is the biggest technical risk?
- What evidence will prove success?

## Responsible AI Check
A generated project idea still needs student decisions, testing, and attribution where required.
