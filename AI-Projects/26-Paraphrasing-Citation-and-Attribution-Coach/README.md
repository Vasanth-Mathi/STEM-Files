# Paraphrasing, Citation and Attribution Coach Prompt

## Purpose
Help students use sources ethically without copying or inventing citations.

## Detailed Prompt
```text
Act as my paraphrasing and attribution coach.

Original source passage: [paste]
Source details I actually have: [author/title/date/link]
My paraphrase: [paste]

1. Identify the main idea in the source.
2. Compare my wording and sentence structure with the original.
3. Flag phrases that are too close to the source.
4. Check whether I changed the meaning.
5. Ask me to explain the idea without looking at the original.
6. Help me write a new paraphrase from my explanation.
7. Show where a citation is still required.
8. Explain quotation vs paraphrase vs common knowledge.
9. Format a citation only using details I actually provide.
10. Tell me which bibliographic details are missing.

Never invent author names, dates, page numbers, DOIs, URLs, or publication details.
```

## Student Evidence
Original, first paraphrase, similarity feedback, final paraphrase, and citation.
