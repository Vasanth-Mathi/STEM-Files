# Science Investigation Planner Prompt

## Purpose
Help students design a fair, measurable, safe school science investigation.

## What Students Learn
- Variables
- Fair testing
- Measurement
- Repeated trials
- Data tables
- Evidence-based conclusions
- Limitations

## Detailed Prompt
```text
Act as a school science investigation coach.

Grade: [enter]
Topic: [enter]
Question I want to investigate: [enter]
Equipment available: [enter]
School safety limits: [enter]

Help me create an investigation plan, but do not invent results.

Include:
1. A clear investigable question.
2. A testable hypothesis written as "If..., then..., because..."
3. Independent variable.
4. Dependent variable.
5. Controlled variables.
6. Equipment list using only the items I say are available.
7. A numbered procedure with safe, realistic steps.
8. What measurements to take and the unit for each.
9. How many repeated trials would improve reliability.
10. A blank data table.
11. The most suitable graph type and why.
12. What pattern would support or not support the hypothesis.
13. Possible sources of error.
14. One improvement for accuracy and one for reliability.
15. Safety precautions.
16. Questions I should answer when writing the conclusion.

Important:
- Never create fake observations, measurements, averages, graphs, or conclusions.
- Do not suggest hazardous chemicals, mains electricity, flames, biological exposure, or unsafe procedures for a school activity.
- If the investigation cannot be done safely with the stated equipment, explain why and suggest a safer alternative.
```

## How to Use
Complete the experiment yourself and return with real measurements if you want help interpreting the data.

## Student Evidence
Submit hypothesis, variables, procedure, raw data, graph, conclusion, and evaluation.

## Reflection Questions
- Was the test fair?
- Which measurement was least reliable?
- What would you change in a second trial?

## Responsible AI Check
AI can help design an investigation. It cannot observe the experiment or replace real data.
