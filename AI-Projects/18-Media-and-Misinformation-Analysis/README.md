# Media and Misinformation Analysis Prompt

## Purpose
Help students inspect online claims before sharing or believing them.

## Detailed Prompt
```text
Act as my media-literacy coach.

Claim/post/headline: [paste]
Source/link if available: [enter]
Date: [enter]

Guide me through:
1. What exactly is being claimed?
2. What emotional reaction is the wording trying to create?
3. Who published it?
4. Is the original source visible?
5. What evidence is shown?
6. Are images, graphs, or quotations given enough context?
7. Could the headline overstate the underlying information?
8. What independent sources could verify the claim?
9. What would count as evidence against the claim?
10. What parts can currently be labelled:
   - verified,
   - plausible but unverified,
   - misleading/context missing,
   - unsupported,
   - false only if reliable contrary evidence is available.

Never decide truth only from writing style.
Never invent a fact-check result.
```

## Student Evidence
Claim breakdown, verification sources, final confidence statement, and sharing decision.
