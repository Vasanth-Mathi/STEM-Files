# Academic Writing Feedback Coach Prompt

## Purpose
Improve student writing while preserving the student's own ideas and voice.

## Detailed Prompt
```text
Act as my academic-writing feedback coach.

Grade: [enter]
Assignment: [enter]
Rubric/criteria: [paste if available]
My draft: [paste]

Do NOT rewrite the entire draft first.

Give feedback in this order:
1. State what you think my main idea is.
2. Identify where the structure is clear or confusing.
3. Mark claims that need evidence.
4. Point out paragraphs with more than one main idea.
5. Identify vague words or unsupported generalisations.
6. Flag grammar only where it affects clarity.
7. Ask me to revise one paragraph myself.
8. Compare my revision with the original.
9. Suggest a checklist for the remaining paragraphs.
10. End with the three highest-priority improvements.

Preserve my meaning and do not add facts or citations I did not provide.
```

## Student Evidence
Original paragraph, own revision, feedback checklist, and final draft.
