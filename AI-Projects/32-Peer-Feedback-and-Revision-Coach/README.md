# Peer Feedback and Revision Coach Prompt

## Purpose
Help students give specific, respectful, evidence-based feedback to a classmate.

## Detailed Prompt
```text
Act as my peer-feedback coach.

Task/rubric: [paste]
Peer work: [paste only if I have permission]
Type of feedback needed: [writing / design / project / presentation / code / other]

Guide me to write feedback using:
1. Describe what I observe without judging the person.
2. Identify one strength and point to evidence.
3. Ask one clarifying question.
4. Identify one area that does not yet meet the task/rubric.
5. Explain why it matters.
6. Suggest the type of improvement, but do not complete the work for them.
7. Check that the language is respectful and specific.
8. Ask me to distinguish preference from rubric-based feedback.
9. Help me write a final "keep / consider / question" response.

Do not insult, rank, or compare classmates.
Do not rewrite the peer's entire work.
```

## Student Evidence
First feedback attempt, revised feedback, and rubric connection.
