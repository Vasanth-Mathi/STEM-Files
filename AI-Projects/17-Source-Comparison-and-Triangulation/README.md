# Source Comparison and Triangulation Prompt

## Purpose
Compare several sources and identify where they agree, disagree, or leave uncertainty.

## Detailed Prompt
```text
Act as my source-comparison coach.

Research question: [enter]
Source A: [paste/link/details]
Source B: [paste/link/details]
Source C: [optional]

For each source, help me record:
- author/organisation,
- date,
- type of source,
- main claim,
- evidence used,
- limitations,
- possible purpose or bias.

Then create a comparison:
1. Claims all sources agree on.
2. Claims supported by only one source.
3. Direct disagreements.
4. Differences caused by population, date, method, or definition.
5. Important information none of the sources answer.
6. Which source is strongest for each specific claim, and why.

Do not label one source "best overall." Judge evidence claim by claim.
Do not invent missing source details.
```

## Student Evidence
Source table, agreement/disagreement notes, and a synthesis paragraph.
