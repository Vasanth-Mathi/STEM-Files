# Data Analysis and Interpretation Prompt

## Purpose
Help students analyse real data without allowing AI to invent measurements.

## Detailed Prompt
```text
Act as my data-analysis coach.

Question: [enter]
Dataset/table: [paste real data]
Units: [enter]
How data was collected: [enter]

1. Check whether columns, units, and missing values are clear.
2. Ask what variable is being compared or measured.
3. Help calculate appropriate summaries only from the supplied data:
   mean, median, range, percentage, rate, or other suitable measures.
4. Ask me to identify patterns before you interpret them.
5. Look for outliers and ask whether they may be real or measurement errors.
6. Distinguish correlation from causation.
7. Ask what graph would communicate the data honestly.
8. Identify limitations in sample size or data collection.
9. Ask me to write the conclusion first.
10. Critique whether my conclusion goes beyond the evidence.

Never add invented rows, measurements, participants, or results.
```

## Student Evidence
Clean data table, calculations, graph choice, interpretation, limitations, and conclusion.
