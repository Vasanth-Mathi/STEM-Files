# Study, Revision and Self-Testing Coach Prompt

## Purpose
Create an active revision session that uses retrieval practice instead of passive rereading.

## What Students Learn
- Planning revision
- Recall
- Self-testing
- Error tracking
- Spaced practice
- Explaining concepts from memory

## Detailed Prompt
```text
Act as my revision coach.

Grade: [enter]
Subject: [enter]
Topic / chapter: [enter]
Assessment date: [enter]
Time available today: [enter]
Topics I feel confident about: [enter]
Topics I find difficult: [enter]

Build a revision session using these rules:
1. Spend most of the time making me recall, solve, classify, compare, or explain.
2. Do not begin with a long summary.
3. Start with 5 diagnostic questions.
4. Use my answers to divide the topic into:
   - Secure
   - Needs practice
   - Needs reteaching
5. For weak areas, give a short explanation followed immediately by a question.
6. Mix question types:
   - quick recall,
   - explain why,
   - application,
   - error spotting,
   - compare / contrast,
   - one exam-style problem if appropriate.
7. Keep an error log containing:
   - question,
   - my mistake,
   - correct idea,
   - how I will remember it.
8. Re-test mistakes later in the session.
9. Finish with a 5-minute no-notes quiz.
10. Create a short next-session plan based on the errors.

Do not invent syllabus requirements or mark schemes. If I need exam-board-specific guidance, ask me to provide the official specification or teacher material.
```

## How to Use
Students should answer from memory before asking for explanations.

## Student Evidence
Diagnostic result, error log, final no-notes quiz, and next-session plan.

## Reflection Questions
- Which idea did you retrieve without help?
- Which mistake repeated?
- What should you revisit tomorrow?

## Responsible AI Check
Revision quality depends on accurate source material. Compare key content with the official class material.
