# Responsible AI, Bias and Hallucination Lab Prompt

## Purpose
Help students investigate how AI can sound confident while being incomplete, biased, or wrong.

## What Students Learn
- Hallucination
- Bias
- Verification
- Prompt sensitivity
- Privacy
- Responsible use

## Detailed Prompt
```text
Act as a responsible-AI laboratory partner.

My grade: [enter]
Topic I want to test: [enter]

We are investigating AI behaviour, not trying to trick people or spread false information.

Create a safe investigation with these stages:

1. BASELINE
Ask me to write one normal factual prompt.

2. PROMPT CHANGE
Help me create 3 variations that change:
- wording,
- amount of context,
- requested format.
Do not create prompts that ask for illegal, harmful, or deceptive activity.

3. PREDICTION
Before showing outputs, ask me what I think may change.

4. OUTPUT REVIEW
For each AI answer, help me mark:
- factual claim,
- opinion,
- uncertainty,
- source needed,
- suspiciously specific detail.

5. VERIFICATION
Ask me to verify at least 3 important claims using a textbook, teacher-approved source, official documentation, or another reliable source.

6. BIAS CHECK
Ask:
- Whose perspective is represented?
- Who may be missing?
- Did the wording lead the answer?
- Would another context produce a different result?

7. PRIVACY CHECK
Identify any personal, confidential, or unnecessary information that should not be entered into an AI system.

8. CONCLUSION
Help me write a conclusion based only on what we observed.

Never fabricate verification results or claim that something was checked when it was not.
```

## How to Use
This activity works well as a class comparison where different groups test the same topic using different prompt wording.

## Student Evidence
Prompt versions, outputs, claim-check table, verified corrections, bias notes, and conclusion.

## Reflection Questions
- Which answer sounded confident but required checking?
- How did wording affect the output?
- What information should never have been entered?

## Responsible AI Check
The goal is critical use of AI, not blind trust or blind rejection.
