# Design Thinking

Design Thinking is a human-centered problem-solving approach used to understand real needs, define meaningful problems, generate ideas, build prototypes, test solutions, collect feedback, and improve designs through iteration.

## How Design Thinking Works

A typical design-thinking process moves through connected stages rather than a rigid straight line.

```text
Empathize ---> Define ---> Ideate ---> Prototype ---> Test ---> Improve
```

Learners first investigate the people, context, and need behind a problem. They then define the challenge clearly, generate multiple possible solutions, create prototypes, test them, gather feedback, and refine the solution based on what they learn.

## Common Use Cases

- Student innovation challenges
- Product design
- Engineering projects
- Community problem-solving
- Classroom design challenges
- Prototype development
- User-centered solutions
- STEM competitions
- Assistive technology concepts
- Service improvement ideas
- Research and feedback activities
- Iterative project development
